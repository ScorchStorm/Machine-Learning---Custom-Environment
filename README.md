## Overview
**Project Title**:
**Machine-Learning---Custom-Environment**

**Project Description**:
This project contains a custom PettingZoo environment that can be used to train 6 AI by playing against each other. The environment is a very simple game inspired by the 2007 Wii game "Star Trek Conquest".

## Development Environment 

To recreate the development environment, you need the following software and/or libraries with the specified versions:
* Python version 3.11.2 - 64 bit
* Visual Studio Code version 1.96.4
* gymnasium version 1.0.0
* numpy version 2.2.3
* pettingzoo version 1.24.3
